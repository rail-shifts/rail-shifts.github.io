מדריך פקודות Git

כלי ניהול ושליטה בלעדי לבעל המערכת • מסונכרן למחשב ולטלפון

1. שגרת עבודה יומיומית

בדיקת מצב (אילו קבצים שונו, מה מוכן לשמירה ובאיזה ענף אתה)
git status
מכין את כל הקבצים ששונו בתיקייה לקראת שמירה
git add .
שומר נקודת ציון מקומית עם הסבר על מה ששינית
git commit -m "הסבר כאן"
מעלה את כל השמירות מהמחשב ל-GitHub
git push
מוריד שינויים מ-GitHub ומעדכן את המחשב המקומי
git pull

2. ענפים ומיזוגים (Branches & Merges)

מציג את רשימת הענפים ובאיזה מהם אתה עובד כרגע
git branch
עובר לענף קיים אחר (למשל Test)
git checkout Test
יוצר ענף חדש מתוך המצב הנוכחי ועובר אליו מיד
git checkout -b new-branch
ממזג לתוך הענף הנוכחי שלך שינויים מענף אחר
git merge branch-name
מוחק ענף מקומי במחשב (שרק אם כבר מוזג בהצלחה)
git branch -d branch-name
מוחק ענף מרוחק מהאתר של GitHub
git push origin --delete branch-name
דריסה בכוח של ענף מרוחק ב-GitHub (שימוש זהיר בלבד)
git push origin main --force

3. בדיקות והשוואת גרסאות

בודק אם יש חדש ב-GitHub בלי לשנות שום קובץ במחשב
git fetch
מציג שורה-אחר-שורה את השינויים שביצעת וטרם נשמרו
git diff
מציג רשימה מקוצרת של 5 השמירות האחרונות שבוצעו
git log --oneline -5
מציג מי כתב כל שורה בקובץ ובאיזה תאריך וקומיט
git blame index.html

4. ביטולים, שחזורים ומכונת זמן

מבטל שינויים בקובץ מקומי ומחזיר אותו לשמירה האחרונה
git restore index.html
מבטל git add (מוציא את הקובץ מההכנה לשמירה)
git restore --staged index.html
מחזיר את הבראנץ' הנוכחי קומיט אחד שלם אחורה
git reset --hard HEAD~1
יומן כל הפעולות שבוצעו במחשב (מכונת זמן לכל נקודה)
git reflog

5. הגדרות משתמש וזהות ב-Git

בדיקת שם המשתמש שמוגדר כרגע במחשב שלך
git config user.name
הגדרת שם המשתמש שייחתם על כל קומיט עתידי
git config --global user.name "rail-shifts"
הגדרת האימייל שיקושר לחשבון ה-GitHub שלך
git config --global user.email "..."
לא נמצאו פקודות התואמות לחיפוש שלך
